# Desafios Bootcamp Python
Repositório dedicado aos desafios de código e projetos práticos desenvolvidos durante o Bootcamp Santander: Dados com Python e IA

# Tecnologias utilizadas: 
* Python (linguagem de programação)

# Conteúdos do bootcamp:
* Fundamentos de Python e Lógica
* Programação Orientada a Objetos - POO
* Banco de Dados e SQL

# Estrutura do Repositório:
* Classificador de ordem: realiza o recebimento de entradas do usuário e, com base em regras de ordenação, classifica os dados através de estruturas condicionais e desempacotamento de variáveis. 

* Classificador de sequência: analisa listas de tamanhos variáveis. Fazendo uso de laços de repetição e variáveis de controle, identifica padrões para determinação de sequências em ordem crescente, decrescente ou mista.
